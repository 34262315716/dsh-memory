# 01 · 模块构造

> 对应 v0.16.2。本章回答：**有哪些模块、谁依赖谁、想改某功能该动哪个文件**。
> 装配入口是 `lib/index.js`（只做组装，不含业务），业务全在独立模块里。

## 1.2 各模块职责与导出

| 模块 | 关键导出 | 职责 |
|---|---|---|
| `lib/index.js` | `apply` `name` `inject` `Config` `scopeOf` `buildHealthReport` | 装配：设置面 → store/embedder 初始化 → Web 路由 → 三条管线 → 工具 → `ctx.memory` 门面 → dispose；含旧库迁移与误配置护栏 |
| `lib/compat.js` | `createSettingsFace` `plainConfig` `volatileTable` `safeGet` `settingsApiOf` `legacySettingsNamespace` `ownEntryId` | 跨内核兼容层。**绝不静态导入 `@deepseek-ai/dsh-settings` 的命名导出**——0.2.0-rc.2 上那是模块求值期 SyntaxError，宿主直接 exit 1 |
| `lib/config.js` | `Config` `resolveStepInterval` `INJECT_PACE_STEPS` `INJECT_PACE_LABELS` | 全部参数 / 开关 / 子对象 schema 与默认值（唯一真源） |
| `lib/util.js` | `scopeOf` `formatNow` `estimateTokens` `renderInjection` `renderPinned` `extractUserText` `stripInjectedNoise` `readCredential` `OUTCOME_RE` | 纯函数与常量；`scopeOf(session, registry)` 是三态 scope 分层的唯一判据 |
| `lib/store.js` | `MemoryStore` `tokenize` `jaccard` `cosine` `ruleEmbed` `VEC_DIM` `EDGE_TYPES` `GRAPH_STOP_WORDS` | 全部数据访问：SQLite / 迁移、CRUD、世界线版本、三路 RRF 检索 + 精排、图谱、社区、主题、事件、日志、遗忘、管家 |
| `lib/embedder.js` | `createEmbeddingServices` `RuleEmbedder` `RemoteEmbedder` `RemoteReranker` | 向量 / 重排 seam；降级链 `onnx → remote → rule`（rule 永不失败） |
| `lib/refiner.js` | `extractWithLlm` `summarizeSessionWithLlm` `mergeMemoriesWithLlm` `llmStrictJson` `normalizeItems` `pickKeywords` `parseJsonLoose` `repairTruncatedJson` `reasoningParam` `isTransientAdapterError` | 把一轮对话蒸馏成自包含记忆：松 JSON 解析、截断修复、瞬时故障重试、时间预算续跑、按 provider 分派的关思考姿势 |
| `lib/write-gate.js` | `createWriteGate` `WORTH_RECORDING_PROMPT` | 写入侧决策门：问本机决策模型"这轮值得记吗"，**非对称采信**（只有高把握说不值得才生效） |
| `lib/link-suggest.js` | `suggestLinks` `LINK_TAU` `LINK_TAU_CROSS_SCOPE` `LINK_MAX_PER_MEMORY` `LINK_TOPK` `LINK_LAYERS` | 语义连边判定（纯函数）：阈值 → 互为最近邻 → 上下文守卫 → 度数上限 |
| `lib/graph-snapshot.js` | `buildGraphSnapshot` | 记忆级图谱快照投影（一记忆一节点 + 边 + 主题 + 事件） |
| `lib/work-projection.js` | `attachWorkProjection` `extractWorkText` `workProjectionInit` `workProjectionApply` | 工作上下文投影单元：由框架订阅 `session/event` 折叠出"最近在干什么"，供 pre-step 取检索 query |
| `lib/web-fence.js` | `fenceWebRoute` `isLoopbackRequest` `SECURITY_HEADERS` | Web 路由信任围栏（回环 + 同源）；框架不替插件鉴权 |
| `lib/pipelines/write.js` | `attachWritePipeline` `isTrivialTurn` | turn/end 沉淀：价值门 → 决策门 → 提取 → 去重合并 → 图谱 → 管家触发 |
| `lib/pipelines/inject.js` | `attachInjectPipeline` `attachPreheatPipeline` | pre-step 检索注入（两触发源 / 节流 / 去抖 / 预算 / 常驻通道）+ 会话预热（双通道） |
| `lib/tools/*.js` | `registerTools` `makeSafeRegister` `makeLogStore` | 工具注册，按域隔离，单个失败不影响其他 |

## 1.3 依赖方向（严格单向，无循环）

```
无项目依赖        lib/util.js          lib/config.js
                    │  ▲                  │
数据访问口        lib/store.js ◀──────────┘   lib/link-suggest.js（被 store 消费）
                    │  ▲
能力 seam    lib/embedder.js │  │  lib/refiner.js        lib/work-projection.js
                    │  ▲     │  │        │
逻辑层        ┌─────┴──┴─────┴──┴────────┴─────┐
              lib/pipelines/*   lib/tools/*   lib/graph-snapshot.js
                    │                 │      lib/write-gate.js
装配壳        └─────────►  lib/index.js（apply 组装一切）  ◀──── lib/compat.js
                          DSH 运行时（cordis 加载 apply/inject/事件/路由）
```

- 依赖的宿主包：`@deepseek-ai/{cordis,schemastery,dsh-llm,dsh-tools,dsh-settings}`，由 DSH 提供，不随本包安装。
- 运行期依赖只有 `sqlite-vec`（构建期 `esbuild`）。
- **单向铁律**：底层（util / store）永不 import 上层（pipelines / tools / index）。加新模块时照此摆放。

## 1.4 想改什么 → 去哪个文件

| 想改 | 去这里 |
|---|---|
| 配置项 / 默认值 | `lib/config.js`（+ `client/settings.jsx` 加 GUI 字段） |
| SQL / 表 / 检索质量 | `lib/store.js` |
| 换嵌入 / 重排服务商 | `lib/embedder.js` |
| 蒸馏 prompt / 提取规则 / 重试策略 | `lib/refiner.js` |
| 写入侧决策门（该不该记） | `lib/write-gate.js` |
| 沉淀逻辑 / 价值门 / 去重 | `lib/pipelines/write.js` |
| 注入时机 / 节流 / 预算 / 注入格式 | `lib/pipelines/inject.js` |
| 语义连边判定 | `lib/link-suggest.js` |
| 图谱快照字段 | `lib/graph-snapshot.js` |
| 工具增删 / schema | `lib/tools/<域>.js` + `lib/tools/index.js` |
| 两代内核的行为差异 | `lib/compat.js` |
| Web 端点鉴权 | `lib/web-fence.js` |
| 插件如何启动 / 装配 | `lib/index.js` 的 `apply` |
| GUI | `client/{settings,graph,logs}.jsx` + `client/index.jsx` 插槽 |
