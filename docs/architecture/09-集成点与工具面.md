# 09 · 集成点与工具面

> 对应 v0.16.2。本插件与 DSH 的每一个接触点，以及暴露给模型的全部工具。

## 9.1 DSH 集成点

| 集成点 | 用途 | 备注 |
|---|---|---|
| `session/event` | 写入原料（turn/end 折叠） | 会话事件流 |
| `agent/pre-step` | 注入（waterfall，追加 `decision.messages`） | 检索注入主通道 |
| `agent/created` + `systemPrompt.section()` | 会话预热（通道 A） | 0.2.0-rc.2 |
| `agent/session-start` + `agent.inject()` | 会话预热（通道 B） | 0.1.x |
| `ctx.settings` | 设置注册 / 读取 | 两代机制不同，见 [08](08-配置与双内核.md) |
| `ctx.tools` | `defineTool` 注册工具 | 按域拆分 |
| `ctx.llm.stream()` | refiner 提取、会话汇总、LLM 归并 | **必须传 sessionId**（见 §9.4） |
| `ctx.credentials` | 密钥读写 | 只存引用，不回显值 |
| `ctx.workspaceRegistry` | scope 解析 | scope 三态层的中间层 |
| `sessionProjections` | 工作上下文投影（`lib/work-projection.js`） | 官方扩展点，框架负责订阅 |
| webServer 路由 | `/dsh-memory/{graph,logs,health}` | 自带回环围栏 |
| client 插槽 | `settings.section` / `sidebar.footer.action` | 两代同名，无需分支 |
| `exports["./client"]` | 双面插件（host + client） | package.json 声明 |

| 域 | 文件 | 工具 |

### 名称相关

| 工具 | 说明 |
|---|---|
| `memory_pin` | 钉选 / 取消 / 查看常驻记忆（恒定注入，不走检索） |
| `memory_archive` | 归档管理：列出被归档的记忆、一键恢复（归档不删除） |
| `memory_theme_relabel` | 存量主题治理：按簇用 LLM 重命名标签；`recluster` 先全量重聚类 |
| `memory_reprocess` | 降级记忆重写。**v0.12.6 起名 `memory_rewrite`，v0.14.0 改名为 `memory_reprocess`**——原名与 DSH 内核自带的 `memory_rewrite` 撞车，同名工具在同一进程里会互相遮蔽 |
| `memory_reembed` | 维度迁移或嵌入失败后补写缺失向量 |

## 9.3 CLI 与运维脚本

| 脚本 | 用途 |
|---|---|
| `node build-client.mjs` | 改 `client/*.jsx` 后重建 `lib/client.js`（bundle 勿手改） |
| `node rebuild-graph.mjs` | 图谱重建（真嵌入归一化重建 + 语义边） |
| `node tools/deploy.mjs` | 部署副本同步（自动 md5 复验；`--check` 只比对，有漂移退出码 1） |
| `tests/test-*.mjs` | 守护测试套件（28 个文件，见 [10-工程约定](10-工程约定.md) §10.4） |

⚠️ `deploy.mjs` 的目标写死为默认家目录下的 `~/.dsh/profiles/<profile>/node_modules/dsh-memory`——**DSH_HOME 不在默认位置时它认不出真正跑着的实例**。先按端口查进程命令行确认 DSH_HOME 与 profile，再决定要不要同步。

## 9.4 调 DSH 流式接口的硬规矩

从 `llm.stream()` 拿结果时，两条每次都适用的规矩：

1. **绝不中途抛异常**：上游的一切失败（400 / 配额 / 空响应 / 上下文溢出 / 超时）都被编码进**终止块**的 `reason`（`{kind, failure?}`）——`kind: 'stop'` 但内容为空同样算失败。判定必须看终止块，不能只看有没有异常。
2. **必须传 sessionId**：不传会被上游按"无会话"处理（详见 [11-已知限制与演进](11-已知限制与演进.md) §11.3 的结案记录）。
