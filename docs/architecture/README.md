## 一句话理解这个插件

**用户每条消息都触发一次检索注入**（可按需关掉），agent 自主工作的其余步骤按节奏补充；每个轮次结束时自动沉淀新记忆，写入前先问一次本机决策模型"值不值得记"。
记忆不是清单，而是会生长的知识网络：分层（ep/sm/画像）+ 图谱 + 世界线（时间维度）+ 向量语义检索。
